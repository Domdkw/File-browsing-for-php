

该项目是一个基于 PHP 的文件浏览工具，具有以下特点：

### 简介
这是一个用于浏览服务器上文件和文件夹的轻量级 PHP 项目。它提供了一个简洁的前端界面，能够展示文件夹内容，并支持导航和快速链接功能。

### 功能
- **列出子文件夹和文件**：通过 `api.php` 提供的接口，可以递归列出指定目录下的所有子文件夹和文件。
- **友好的前端界面**：使用 `index.html` 和 `style.css` 提供了美观的用户界面，便于浏览和操作文件。
- **支持快速访问链接**：页面中包含快速访问链接，方便用户快速跳转至常用目录。
- **图标支持**：项目中引入了 SVG 图标（如 Bilibili、GitHub 等），用于增强界面的可视化体验。

### 使用说明
1. **部署环境**：确保服务器支持 PHP，并将项目文件放入服务器的 Web 根目录或指定目录。
2. **访问页面**：在浏览器中打开 `index.html`，即可看到文件浏览界面。
3. **配置 API**：修改 `api.php` 中的目录路径，以指定需要浏览的文件目录。
4. **使用功能**：通过导航栏和文件列表进行文件浏览，利用快速链接跳转到特定目录。

### 目录结构
- `api.php`：PHP 文件，提供文件和文件夹列表的 API 接口。
- `index.html`：前端页面，主界面展示文件浏览内容。
- `style.css`：样式文件，控制前端页面的外观。
- `icon/`：存放 SVG 图标资源。
